# FamilyHub 👨‍👩‍👧‍👦 - Releases & OTA Updates

Benvenuto nella repository pubblica di **FamilyHub**!

Questa repository funge esclusivamente come **CDN (Content Delivery Network)** e server di distribuzione per gli aggiornamenti OTA (Over-The-Air) dell'applicazione FamilyHub per dispositivi Android.

> 🔒 **Nota:** Il codice sorgente dell'applicazione FamilyHub è privato. Questa repository contiene unicamente i file eseguibili (`.apk`) nelle varie versioni rilasciate.

## Come scaricare l'app
Puoi scaricare l'ultima versione dell'app per Android direttamente dalla sezione **[Releases](https://github.com/rinaldinichristian/FamilyHub-Releases/releases)** a destra in questa pagina.

## Sistema di Aggiornamento
L'applicazione è dotata di un sistema di auto-aggiornamento integrato. Una volta installata la prima versione, l'app controllerà automaticamente la presenza di nuove release su questa repository e ti proporrà l'installazione nativa senza dover tornare su questa pagina.

---
*FamilyHub è l'app definitiva per la gestione dei menù settimanali, della spesa e del ricettario di famiglia.*
